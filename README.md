<h2 align="center">🙋 About Me</h2>

I'm a full-stack developer from Cambodia who loves turning ideas into things people can actually use. I enjoy working across the whole stack, from a clean, friendly interface to the API and database behind it, and I care about code that's readable, practical, and kind to whoever opens it next.

When I'm not building, you'll usually find me reading docs, taking things apart to see how they work, or trying to explain a tricky concept in simple words. To me, good software and good teaching have a lot in common: both make complicated things feel approachable.
